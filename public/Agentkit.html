任务完成度 优化建议

↑ 高优先级 33.8%

分析失败模式
对所有低分样本逐条 review，统计失败的共性特征（理解偏差、格式错误、信息缺失等）。
优化 Prompt 描述
检查 Agent 的系统提示是否清晰表达任务目标，避免歧义；针对失败类型补充示例。
🧹 清洗测试数据

⚙️ 检查输出解析

优化兜底策略
为高频失败场景添加 fallback 逻辑，防止 Agent 在无法完成时给出误导性回复。

轨迹质量 优化建议

↑ 高优先级 35.0%

执行轨迹质量严重偏低，Agent 存在明显的低效执行问题。

🔁 检测循环调用
分析是否有样本出现工具重复调用或调用风暴，这是轨迹质量最严重的问题。
📉 优化规划能力
检查 Agent 的任务分解逻辑，减少不必要的中间步骤和探索性调用。
梳理调用约束
确认 Agent 是否正确理解工具间的前置条件和顺序依赖，避免乱序执行。
✂️ 精简工具定义
过多或描述模糊的工具会增加 Agent 规划负担，可考虑合并功能相近的工具。
